# 요식업 다중 매장 급여 관리 & 명세서·임금대장 발급 웹애플리케이션

여러 매장(브랜드)을 운영하는 요식업 대표 1인이 사용하는 전용 급여 관리 반응형 한국어 웹애플리케이션입니다.
매장별 직원 관리, 근태 캘린더 입력, 2024~2026 최신 노동법 기준 급여 자동 계산(구간분할 일할계산, 통상임금, 이중신고구조, 수습감액 법정 적법성 검증), 6대 급여 검수 및 확정 절차, 1인 1장 급여명세서 및 2행 구조 임금대장 PDF/Excel 발급, 전체 매장 통합 대시보드를 완벽하게 지원합니다.

---

## 🌟 주요 기능 및 특징

1. **대표자 1인 전용 보안 로그인 & 다중 매장 관리**
   - JWT 기반 인증 및 AES-256 주민등록번호 양방향 암호화 저장 및 UI 마스킹(`900101-1******`)
   - 매장별 시급제/월급제 기본값 및 산재보험 업종요율(기본 0.9%) 관리
   - 매장별 데이터 완전 격리 및 상단 글로벌 매장 전환 바

2. **지능형 직원 관리**
   - 상용직 / 일용직, 월급제 / 시급제 지원
   - **2026년 법정 최저시급(10,320원) 하한선 자동 검증**: 최저시급 미만 입력 시 저장 차단
   - **수습감액 법적 적법성 자동 판정**: 1년 미만 근로계약 또는 단순노무직인 경우 최저임금법 시행령에 따라 수습감액 설정이 자동 비활성화됨
   - **4대보험 이중신고구조(관리자 전용)**: 계약급여와 신고기준액 차이(미신고차액)에 대해 원천공제율(기본 10%) 적용 세후 금액 산출 및 명세서 표시 모드(사업자/개인통장 2줄 분리 or 미신고공제 단일행) 선택

3. **월간 근태 캘린더 & 공휴일 연동**
   - 월간 인터랙티브 캘린더 + 시간 피커/직접입력 지원
   - 대한민국 법정공휴일(대체공휴일 포함) 자동 연동 및 임시공휴일 수동 추가/삭제
   - 순근무시간, 연장근로(8h 초과 1.5x), 야간근로(22:00~06:00 0.5x 가산), 주말휴일(1.5x/2.0x), 공휴일(1.5x/2.0x) 자동 판별
   - **빠른입력 모드**: 휴무일만 지정하면 고정근무시간대로 한 달치 근태 일괄 자동 생성
   - **엑셀 일괄 업로드**: 한 달치 매장 근태 엑셀 파일 일괄 반영

4. **급여 계산 및 필수 6대 검수 워크플로우**
   - **역일수 기준 구간분할(Segment Proration) 일할계산 엔진**: 중도입사, 중도퇴사, 수습종료일 변경 시점 구간 분할 계산
   - **통상임금 산정**: 2024 대법원 전원합의체 판결 반영
   - **6대 자동 검증 규칙**: 실지급액 수식 대사, 음수/빈값 검사, 4대보험 요율 대사, 근태 시간 대사, 필수값 체크, 중복 방지
   - **전월 대비 변동 분석**: 전월 대비 지급총액 ±30% 이상 변동 시 강조 표시 및 산출식 비교 모달
   - **확정 잠금 & 재오픈 절차**: 전 직원 검수 완료 시에만 확정 가능, 재오픈 시 사유 감사로그 기록

5. **표준 서식 발급 (PDF / Excel)**
   - **급여명세서**: 1인 1장 표준 양식, 수당별 자연어 산출식 기재, 대표 직인 서명란, 이중신고 분리 안내
   - **임금대장**: 직원 1명당 2행 구조(1행: 주요 지급/공제, 2행: 지방소득세/수습공제/보조항목)의 정통 임금대장
   - ExcelJS 기반 셀 서식 완벽 재현 엑셀 및 고품질 인쇄/PDF 지원

## 🚀 설치 및 실행 방법

### 1. 사전 요구사항
- Node.js v20+ (Node.js v24 권장)
- npm v10+

### 2. 패키지 설치
```bash
# 루트 의존성 설치
npm install

# 클라이언트 의존성 설치
npm --prefix client install
```

### 3. 초기 시드 데이터베이스 생성
```bash
npm run seed
```
> 시드 데이터 실행 시 관리자 계정(`admin` / `admin1234!`), 매장 3개, 직원 12명(이중신고, 외국인, 수습직원 포함), 2026년 8월/9월 근태 및 급여 내역이 자동으로 구축됩니다.

### 4. 개발 서버 실행
```bash
npm run dev
```
- 프론트엔드: `http://localhost:3000`
- 백엔드 API: `http://localhost:5000`

### 5. 단위 테스트 실행
```bash
npm test
```

### 6. 프로덕션 빌드 및 단일 서버 구동
```bash
npm run build
npm run server
```
